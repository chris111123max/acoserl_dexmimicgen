# ACo-SERL 基础模块实施与专项验证报告

日期：2026-10-29。分支 codex/acoserl-intervention-foundation。本轮没有正式训练、梯度更新、BC预训练或通用冒烟测试，没有更换视觉编码器，也没有覆盖旧训练产物。完整机制差异、算法设计、文件接口与后续定量验收见 DESIGN_ZH.md。

## 本轮完成范围

统一管理器已经区分 Normal、Guide_A/B、Recover_A/B、Safe_Stop，并为 Recover_Joint 保留明确的拒绝接口。普通窗口引导继续用20mm触发、5mm退出和90度方向条件；双臂窗口长度27/32，接管期间被动保持不再推动参考时间。引导与两点恢复复用原OSC反馈控制和原被动臂动态保持资格，不放宽2mm末端、3mm持物及80N力限制。

新增工作空间动作风险估计、候选优先级和拒绝统计。它仅使用现有OSC命令的位移估计，不能证明全动力学/全机器人几何路径安全。硬安全和逐物理子步监测仍保留。提前预警失败或无恢复资格时拒绝执行对应建议动作。

动态Demo仅接收连续、完整执行、通过抓取/物体/被动保持检查并成功交还的接管片段。失败候选不被提升为示范。全部完整真实transition仍进Online；初始224条独立保留；示范侧128条内部默认原始64+动态64，动态为空用原始128。每行有动作来源、阶段、env/episode/frame/takeover及双参考索引。未执行策略建议或部分物理子步不成为Replay行。

安全失败与时间截断采用显式bootstrap字段：完整物理安全失败为terminated且不bootstrap；普通时间和采集停止可bootstrap；拒绝/部分动作只关闭既有真实前缀并禁止bootstrap；恢复超时等监督器停止单独标识为truncated且不bootstrap。严格奖励协议不变，评估与Episode统计读取真实success，不用terminated冒充成功。

新增自主能力统计：只有未受该阶段干预的Policy动作完成阶段事件才计证据；当前仅对已支持的接近/抓取阶段允许减少普通窗口引导。持物/装配阶段不据此自动解锁。需要5次连续完整无干预成功才允许全局退出；原论文l_term低干预条件另外记录，辅助成功不等于自主成功。

持物局部恢复和联合装配恢复仍无当前代码资格，配置设为enabled/validated也不能绕过拒绝接口。没有开发一套完成装配的恢复控制器。四个未来对照方法已有配置选择接口，本轮未运行任何学习对照。

## 从旧日志确认的问题

旧实验60960完整步、255部分物理动作、59916次更新，无干预评估0/20。3289次Safe_Stop中A工作空间越界2042次、A张开夹爪意外接触623次、B越界195次、被动臂漂移163次、力限制部分步255次等。

逐步日志中，A被动保持不准静态拒绝34580次、B拒绝25867次。这些是控制步出现次数，不能当作独立试验或相加计算恢复成功率。旧运行只有201次接管和30次交还。新预警仍不能解决所有高速被动臂状态；要扩大恢复域，需要单独验证双臂减速/保持过程，不能取消现有门禁。

自主退出契约验证：多次辅助成功不会关闭干预，5次完整无干预成功才关闭；高级配置不能伪造Joint资格。动态Replay实际保存重载已验证，新增完整NPU learner checkpoint集成仅完成代码接线和语法检查，未运行新的NPU训练/重载验收。

## 仍然未完成或未证明的部分

1. 持物中的单臂局部恢复没有在当前管理器完成资格验收，仍禁用。
2. 联合接触恢复没有控制器及独立物理证据，Recover_Joint只能拒绝并停止，不能宣称实现联合恢复。
3. 接触图/阶段规则仅在这些示范前缀验证，没有覆盖所有轻触、滑移、异常物体位置或耦合动力学；本轮未构造真实A/B物理耦合恢复试验。
4. 新机制没有证明改善随机Actor的Episode长度或无干预成功率；不得拿脚本回放与旧RL探索做因果比较。
5. 未做新16环境/NPU学习验收。16环境4+4+4+4调度保持，新增经验来源/终止语义需未来专门验收。正式入口要求新的collector_protocol及formal_training_approved门禁，旧gate无法直接启动新实验。
6. 原保持资格偏保守且拒绝频繁。新增预警并不能保证所有被动臂动态状态均可接管；下一步应先验证受控减速/保持和有限持物局部纠偏，再讨论装配联合恢复。
