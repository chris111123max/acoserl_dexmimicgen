## 保留的官方思想和算法

官方 AutoSERL 参考版本为 238271246e39ef0cf7e06a94392c4b2d184a9af2。已核对 wrappers.py、train_rlpd.py 和任务参数。保留独立滑动窗口、全轨迹 cpoint、窗口 pipoint、90°方向过滤、停滞恢复、P0→P1 和低干预成功后的停用逻辑。位置阈值 th2=20 mm、th1=5 mm，l_stag=20，进展阈值5 mm，l_term=10。l_term 不是十步内完成整个任务的要求；本项目额外保留稳定成功和独立安全门禁。

A=右臂robot0，B=左臂robot1；分别抓 piece_1、piece_2，不假设共抓同一物体。A恢复区间30→57，B为38→70；区间长度分别27、32个时间间隔。官方示例以P1-P0+1描述包含端点的样本数，本项目显式区分间隔和样本。窗口初始末端0，无接管时按真实控制步推进，接管期间暂停；真实抓取、释放事件限制合法索引，完成进度不得倒退。参考共230状态，HDF5本身229动作、229保存状态，末状态来自实际回放派生参考，原数据不改写。

冻结的现有ResNet18空间主干、三路RGB84、18维状态、14维联合Actor、10Q、ResFiT官方更新、n=3/gamma=.99、batch256与Online/Demo各128、UTD1均保持。Demo半批使用原始96/动态32，正奖励最低2的既有采样选项；没有动态数据时由原始数据补足。仅224条严格原始transition，额外Dynamic按真实干预产生，未加入BC预训练或改写损失。

## 最小任务执行修复

1. 原近接触几何投影把OSC目标增量误当成50 ms内瞬时位移，连合法装配示范也被投影26步。baseline模式改为用已有固定OSC增益的单周期名义响应，结合实际速度，检查阶段合法的TCP/物体参考走廊。它是任务动作兼容性筛选，不是接触动力学安全证书；实际2 ms硬保护继续工作。
2. 原B释放判断把静态保持资格和游标时滞当成正常释放前提，且在Panda尚未打开时又命令夹紧。保留原6 mm/.1 rad物体走廊，按真实支撑、首件完成和合法释放事件授权有限开爪。Panda夹爪每次积分0.2，完全闭合到完全打开需10条控制命令；沿既有三步settle给出13条有限预算，超过预算仍未完成则停机。游标不被强行跳转。
3. 首件原直接支撑谓词在正常末段出现误报。真实示范有piece_1→piece_2→B/地面的承载转移，以及一个孤立2 ms零接触样本。baseline仅在已授权的有限释放期间认可实际测得的这条任务承载路径；孤立缺失最多允许一个物理子步，并用当前速度、重力和既有2 mm/.035 rad边界检查下一子步预测。第二个连续缺失支撑样本拒绝。原首件和base锚点从不移动，力、位移和姿态阈值不提高。
4. “恢复域未验证”和“正常Actor动作危险”保持分离。普通安全自由空间继续探索；接触恢复高级模式不可用不会自动禁掉合法任务动作。

## 恢复资格与安全交还

baseline.json明确禁用carry_local、joint和passive_brake高级模式。旧持物恢复、接触研究代码及其证据保留，不能把开发测试视为生产授权。第一版正式允许的主动模式为Guide_A/B、Recover_A/B，限定抓取前空手、目标物体仍在验证取物位、无危险接触/耦合、返回通道通过检查，且被动臂保持资格成立的状态。

pregrasp_hold.py复用旧真实P0保持证据，并检查被动臂实际位姿、速度、抓取签名及持物相对变换；没有把旧末端证书推广为任意持物资格。被动臂2 mm、持物3 mm及原姿态/相对抓取约束保留，真实子步继续监控。超出资格时不执行单臂恢复。

交还采用Recovering→Recovery_Stabilizing→Handoff_Ready→Policy_Guarded，目标到达不等于交还完成。稳定抓取/速度/接触/首件保护满足后，先验证实际下一条策略命令，通过真实执行再记录safe_handback。短时测试控制器交还和真实NPU Actor交还分别记录，不能互相冒充。

## 数据与16环境接线

action_provenance.py新增逐臂位姿/夹爪来源及14维专家mask。一臂真实引导/恢复只标该臂7维，被动保持不标专家；纯SafetyProjection不进入Dynamic。三种动作（策略建议、干预建议、最终执行）保持独立，Replay action永远是实际执行动作。特权物体/接触真值只进监督和日志，未加入Actor观测。

Dynamic协议升级为task_interventions_baseline_per_arm_v1，旧协议checkpoint不静默兼容。按env_id/Episode隔离3-step，拒绝未执行/部分物理步伪造transition；终止、截断、拒绝与合法collector切尾使用显式边界。checkpoint保存模型/优化器/Replay/归一化/RNG/窗口审计信息；重启时合法关闭旧尾片段、各worker从新Episode reset，不宣称MuJoCo中途位级续训。

16个CPU MuJoCo worker仍4+4+4+4初始化，全部ready后四组同时派发动作，只有主进程使用NPU。单环境终止只重置对应worker。无NVIDIA EGL依赖，继续OSMesa和单线程BLAS。

有界集成可用 --integration-pregrasp：仅env0/1从canonical0通过实际前缀及保持进入已验证P0场景；每一物理步返回真实图像并写Online，来源DiagnosticPreparation，非策略自主Episode。正式模式禁止此选项，不加载验收模型和验收Replay。准备步骤、恢复步骤和独立评估均单独计数，集成预算最多2048有效真实步。
