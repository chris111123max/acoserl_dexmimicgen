发布副本独立于运行目录：未停止、重启或修改训练，也未修改原始数据、模型、Replay 或运行日志。旧诊断驱动、早期 smoke、无关任务和测试报告按要求排除；原服务器历史文件不删除。

可复现性整理：将旧试验驱动中被训练复用的 object_error 原样移入共享工具；将被窗口过滤器读取的 actual_grasps 关系原样提取为 reference_grasps.json，避免依赖被排除的 outputs；保留严格奖励协议的原始有效行数和奖励/成功向量，仅移除离线审计和回放日志。网络、损失、优化算法和安全阈值均未修改。旧单示范桥接模块只保留正式路径使用的四个数据函数，删除历史测试入口。

隐私处理：服务器绝对路径改成基于仓库位置的路径和 CANN_ROOT；主机名/IP、旧作者身份、旧历史不进入公开历史。原历史扫描的 227 个 blob 中未发现已检查格式的密钥/令牌，79 个含私人路径的 blob 不推送。扫描并非不存在所有未知秘密的数学证明，最终文件清单和摘要保存在 PUBLICATION_MANIFEST.json。

此公开版不携带 datasets、outputs、logs、虚拟环境、缓存、权重、HDF5 或原 Git 历史。正式报告中的历史日志、验收 JSON 和旧文件引用属于服务器证据，未全部随此精简发布提供。公开副本的 deployment_gate 默认关闭，历史部署授权不自动适用于新机器。
